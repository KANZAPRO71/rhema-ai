Kebijakan Privasi – Rhema AI

Terakhir diperbarui: 13 September 2026 · id.rhema.alkitabvoice

Rhema AI (“Kami”) berkomitmen melindungi privasi Anda. Kebijakan ini menjelaskan bagaimana informasi dikelola saat Anda menggunakan aplikasi pendamping ibadah kami yang berbasis Bring Your Own Key (BYOK) dan model Gemini 3.1 Flash Live Preview.

1. Sistem Bring Your Own Key (BYOK) & Keamanan API Key

Aplikasi kami beroperasi sepenuhnya dengan sistem BYOK — Anda membawa API Key Google Gemini milik sendiri.

  • Penyimpanan lokal terenkripsi: API Key yang Anda masukkan disimpan dengan aman di perangkat Anda. Di Android, kami menggunakan EncryptedSharedPreferences dan Android Keystore.
  • Tidak ada transmisi ke server Kami: Kami tidak menjalankan server perantara. API Key Anda tidak pernah dikirim, disimpan, atau dibagikan ke server milik Rhema AI.
  • Kontrol penuh: Anda dapat menghapus atau mengganti API Key kapan saja melalui menu Pengaturan di dalam aplikasi.
  • Validasi Live API: Saat Anda menyimpan key, aplikasi melakukan uji koneksi WebSocket langsung ke Google untuk memastikan key mendukung suara live — tanpa melalui server Rhema.

2. Pemrosesan Data Suara & Audio (Full Duplex)

Untuk fitur asisten suara dua arah (Full Duplex), aplikasi memerlukan akses mikrofon perangkat Anda.

  • Koneksi langsung (Direct WebSocket): Aliran audio dari mikrofon dikirim langsung dari perangkat Anda ke server Google API menggunakan protokol aman wss://generativelanguage.googleapis.com, memakai API Key Anda.
  • Tidak direkam oleh Rhema: Kami tidak merekam, menyimpan, atau mendengarkan percakapan suara Anda di server manapun milik kami.
  • Kebijakan Google: Pemrosesan audio tunduk pada Ketentuan Google Gemini API dan kebijakan Google AI Studio / Google Cloud terkait akun Anda.
  • Mikrofon hanya saat dipakai: Akses mikrofon diminta saat Anda menekan mulai suara — bukan saat aplikasi dibuka.
  • Deteksi krisis: Teks chat berbahaya dipotong sebelum ke Google. Pada sesi suara, audio sudah terkirim ke Google sebelum filter di perangkat menampilkan hotline.

3. Data Lain yang Diproses di Perangkat

  • Teks & gambar — prompt renungan, chat, atau analisis foto dikirim ke Google Gemini saat fitur AI dipakai (memakai key Anda).
  • Transkrip & memori — riwayat suara, sesi chat, dan catatan “ingat bahwa…” tersimpan di perangkat (WebView) lalu dapat dikirim ulang ke Gemini pada giliran berikutnya.
  • Jurnal doa — lokal; dikirim ke Gemini hanya jika Anda meminta AI mendoakan item tersebut.
  • Preferensi lokal — region ibadah, suara AI, highlight ayat, catatan ayat.
  • Alkitab & kidung offline — teks bundled di aplikasi; tidak dikirim ke server Rhema.

4. Iklan Pihak Ketiga

Rhema AI tidak menampilkan iklan (tidak menggunakan Google AdMob atau jaringan iklan lain). Aplikasi ini didukung oleh model BYOK — biaya API (jika ada) ditanggung langsung oleh Anda melalui akun Google AI Studio / Cloud Project Anda.

5. Pihak Ketiga & Google Gemini API

Fitur AI menggunakan Google Gemini API (model preview suara dua arah). Kuota dan biaya (jika ada) ditagihkan oleh Google ke akun API Key / Cloud Project Anda — bukan ke Rhema. Kami tidak menjual atau membagikan data Anda ke pihak ketiga lain.

6. Izin Android

  • Internet — koneksi ke Google Gemini (REST & WebSocket).
  • Mikrofon — suara live full duplex (hanya saat sesi suara dimulai).
  • Audio settings — pemutaran musik ambient & latihan nafas.

7. Hak Pengguna

Karena data (termasuk API Key dan preferensi lokal) disimpan di perangkat Anda, Anda memiliki hak penuh untuk:

  • Menghapus API Key kapan saja via menu Pengaturan.
  • Menghapus seluruh data aplikasi via Clear Data di pengaturan Android.
  • Menghapus instalasi aplikasi — data lokal ikut terhapus.

Cadangan cloud Android dan transfer perangkat ke perangkat lain dikecualikan untuk data aplikasi (termasuk WebView dan kunci). Pertanyaan privasi: kanzapro6@gmail.com

Privacy Policy – Rhema AI

Last updated: September 13, 2026 · id.rhema.alkitabvoice

Rhema AI (“We”) are committed to protecting your privacy. This policy explains how information is handled when you use our worship companion app built on Bring Your Own Key (BYOK) and the Gemini 3.1 Flash Live Preview model.

1. Bring Your Own Key (BYOK) & API Key Security

Our app runs entirely on BYOK — you provide your own Google Gemini API key.

  • Encrypted local storage: Your API key is stored securely on your device. On Android, we use EncryptedSharedPreferences and the Android Keystore.
  • No transmission to our servers: We do not operate intermediary servers. Your API key is never sent to, stored on, or shared with Rhema AI servers.
  • Full control: You may remove or replace your API key anytime in Settings.
  • Live API validation: When you save a key, the app runs a direct WebSocket test to Google to confirm Live API support — without routing through Rhema servers.

2. Voice & Audio Processing (Full Duplex)

Two-way voice requires microphone access on your device.

  • Direct WebSocket: Audio from your microphone is sent directly from your device to Google’s API over secure wss://generativelanguage.googleapis.com, using your API key.
  • Not recorded by Rhema: We do not record, store, or listen to your voice conversations on any server we operate.
  • Google policies: Audio processing is subject to the Google Gemini API Terms and your Google AI Studio / Cloud account policies.
  • Microphone only when in use: The system prompt appears when you tap Start voice — not at cold start.
  • Crisis detection: Harmful chat text is stopped before Gemini. During live voice, audio already reaches Google before the on-device filter shows hotlines.

3. Other On-Device Data

  • Text & images — devotion prompts, chat, or photo analysis sent to Google Gemini when AI features are used (under your key).
  • Transcripts & memory — voice history, chat sessions, and “remember that…” notes stay on device and may be re-sent to Gemini on later turns.
  • Prayer journal — local; sent to Gemini only if you ask the AI to pray those items.
  • Local preferences — worship region, AI voice, verse highlights, notes.
  • Offline Bible & hymns — bundled in the app; not sent to Rhema servers.

4. Third-Party Advertising

Rhema AI does not show ads (no Google AdMob or other ad networks). The app is supported by BYOK — any API costs are between you and Google via your AI Studio / Cloud Project account.

5. Third Parties & Google Gemini API

AI features use the Google Gemini API (two-way voice preview). Quota and any charges are billed by Google to your API key / Cloud Project — not Rhema. We do not sell or share your data with other third parties.

6. Android Permissions

  • Internet — Google Gemini connectivity (REST & WebSocket).
  • Microphone — full-duplex live voice (only when a voice session starts).
  • Audio settings — ambient music & breathing prayer playback.

7. Your Rights

Because data (including your API key and local preferences) stays on your device, you may:

  • Remove your API key anytime in Settings.
  • Clear all app data via Android Clear Data.
  • Uninstall the app — local data is removed.

Android cloud backup and device-to-device transfer exclude this app’s data (including WebView storage and the encrypted API key). Privacy contact: kanzapro6@gmail.com

Intended for teens and adults. The “Sunday School” persona is not unsupervised children’s software.
